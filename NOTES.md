# Hub notes

What a session working on the hub needs to know that no other file holds.

## Found queue

Findings recorded for the next plan (Doctrine §0e rule 2). A finding that was not put right and does not stop the plan it was found in is queued here, one line each, opening with its key. A plan whose Files names the hub answers every line in a `## Found answered` section, one line each, opening with the key and then `fixed in step N`, `carried to step N`, `still queued` or `dropped` (the last two with a reason), and `plan-guard.mjs` refuses the plan until it does. An agent writes this section, in a step of a plan whose Files names this file; the main thread writes no repository file. These lines were recorded on 2026-10-12 by the plan that built the review, the approval's scope, the stop word, the state page, the queue, the shared rules and the card.
