# The rules ledger of 14 November 2026

This is every rule on the hub's rules pages as they stood at commit 4ea3157, the last commit before the rebuild of 11 and 12 November 2026, each checked against the live pages as they stood at commit cc825e2 on 14 November 2026. It records a state and chooses nothing. The files it describes are in plans/rules-ledger/.

## How it was made

For each 150-line range of each old page, one reader listed every rule. A second reader re-read the range for rules the first had missed. A third searched the live pages for each rule. A fourth challenged every rule marked as kept before its file was written. Pages that still existed were audited by their removed lines, not whole. One more reader listed what the hooks told a session.

A rule counts as kept only when a live page was quoted stating all of it, and a doubt counted as dropped.

These pages counted as live: CLAUDE.md, the pages under plans/native, the roles and procedures under .claude, DOCTRINE.md, doctrine/never.md, doctrine/apps.md, HUB-REFERENCE.md, SECURITY.md, REPOS.md, ACCESSIBILITY.md, COLDREAD.md, METADATA.md and PALETTES.md. The archive, the lessons, the findings, the ranked list and the records under plans did not.

## How to read a file

The name of a file in plans/rules-ledger/ is part-, then the old page with its dots and slashes turned to dashes, then the first line of its range, for example part-doctrine-plans-md-0151.json is doctrine/plans.md from line 151 to 300. The file holds source (the old page), commit (4ea3157), range, and rules. part-diff-never.json and part-diff-standing.json cover the passages the rebuild rewrote, and their rules carry a file field naming the page.

Each rule has these fields:

- n: its number within the file.
- start and end: its line numbers in the old page at 4ea3157.
- heading: the heading it sat under.
- quote: the rule's opening words as the page had them.
- says: the whole rule in one sentence.
- enforcer: the gate or hook the page named, if any.
- verdict: carried, partial or dropped.
- where and live_quote: the live line, when one was found.
- missing: what no live page states.

part-other-sources.json lists what the hooks told a session. Its fields are:

- path: the hook file.
- what: when it spoke.
- told: the words it used.
- today: still told, told in part, or no longer told.
- where_today: the live line that tells it, when there is one.

To read an old page at that commit, run this, with the path of the page in place of the angle brackets:

```
git show 4ea3157:<path>
```
