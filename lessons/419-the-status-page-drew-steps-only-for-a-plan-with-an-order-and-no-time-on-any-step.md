## 419 · The status page drew steps only for a plan with an Order line and showed no time on any step, so a plan without one had its chips typed in by hand at every publish; the renderer now draws every plan's steps with start and estimate chips

**Enforced by:** GATE hub:session-guards.test.mjs — the cases that run `report.mjs` over a plan with no Order line and real agent transcripts and read the section of every step, the notes' two new keys, and the chips drawn from a planted state, with plants in `report.mjs` for every part that must fail them

**Recorded 2026-10-20.** The page was drawn from the plan's Order. A plan without an Order line had no pointer, so `pointerState` returned no steps and the page carried no section for any step of it. In the run of 19 October the sections and their chips were typed into the page's source by hand at each publish, and a time on a step, when it started and how long it was expected to take, had no key to be drawn from at all. A hand-kept chip goes at the next rewrite (lesson 414), and a time typed into a chip is a guess that looks like a reading.

**What is done now.** `pointerState` gives a plan with no `Order:` line one row for each number that opens a line of its `## Steps` section, in the order of the steps, with the state an Order step gets: DONE is read by `pointerOf` over an Order line made from those numbers, so the definition of DONE stays the one. `stepChip` takes its held words from the order of those steps when there is no pointer. `managerNotes` reads two keys, `Start 41: 07:15` in California time and `Estimate 41: 25 min`, and `stepTimeChips` draws chips beside the state chip in its colour: a running step shows when it started and the clock time its estimate ends at; a held step shows its estimate in minutes; a done step shows how long it took, from the Start line to the end of the agent whose hand-back opened DONE, the Start line's date taken from that end's date in California, and nothing where the result is negative; a step with no line gets no chip. When any chip is drawn the page's updated line ends with the sentence that estimates are the plan's and not measurements, and otherwise it is as it was. A plan with an Order still draws only the steps in its Order and Standing lines.

**What the check cannot see.** It cannot make the manager write the lines, and a step with no Start line has no time. The duration of a done step is measured to the end of the agent, which is when the work ended, and not to when the manager read its hand-back. A step counted done by decision has no agent that handed back DONE, so it shows no duration. The estimates are the plan's figures and the page says so; whether they were right is read from the done chips beside them.

**The general form.** A shape drawn for one kind of plan is a shape kept by hand for every other kind. Draw it from what every plan has, and take a figure that is a guess from the plan and a figure that is a reading from the clock, never one from the other.
