## 478 · A refusal's words naming an ordinary condition were read as a misread mode, and cost two latches and two owner messages

**Enforced by:** JUDGEMENT — when a gate's refusal names a condition that can be true, the session checks that condition first and believes the words; a defect in the gate is theorised only after the named condition has been read and found false

**Smell:** a session answers a refusal with an account of how the gate must have misread something, before it has read the state the refusal names; the sign is a second call at the same end by another tool or wording, which the latch refuses in turn.

**Recorded 2026-11-08.** Measured on 8 November, California time, in the plan of the standing problems of the gates and the session before it.

**What happened.** An edit of a plan's Goals was refused by the approval guard as a scope edit made outside plan mode. The session read the refusal as the guard misreading the mode, tried the edit by another route, and was refused again; two latches were set and two messages of the owner went to clearing them. The refusal had said what was true: a worker restart after an idle gap had ended the harness's plan mode, and the route it named, the session's own entry to plan mode, was the one that worked. The same gap showed in the plan check and the approval call, which resolved a file of the What is section differently, so a green check was followed by a refused exit; there the words of the refusal were also right.

**What was wrong.** The refusal named an ordinary condition, a mode that had ended, and the session weighed it against its own belief about the mode instead of reading the mode. A refusal is the owner speaking, and a defect in a gate is a finding to file after the work, never a reason to try a second route.

**The test.** Before any thought that a gate is wrong, read the one thing its refusal names, and act on the route it names. Only a refusal whose named condition is false on a read is a defect, and it is then recorded as a finding and the call is not repeated.

**The general form.** A refusal that names a condition is a request to look at that condition; the session that theorises about the gate instead spends the owner's messages on a latch it set itself.
