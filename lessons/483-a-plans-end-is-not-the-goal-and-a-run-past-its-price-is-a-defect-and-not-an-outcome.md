## 483 · A plan's end is not the goal, and a run past its price is a defect and not an outcome

**Enforced by:** GATE hub:hook-dispatch.mjs — the dispatch gate refuses a send once the count of the agents sent under the approval has reached the number of the plan's Sends priced line, and the dispatcher prints the count at every prompt
**Enforced by:** GATE hub:plan-fence.mjs — an agent repairs its own red suite run once, in a file it wrote in the send, so a one-line fix no longer costs a review and a second send

**Smell:** a wave's report says the plan reached its end while the number of sends is more than twice the number the plan priced, and the notes record the overrun as an outcome.

**Recorded 2026-11-10.** Measured on 9 November, California time, over four waves of the batch.

**What happened.** Four waves ran thirteen, seventeen, fourteen and thirty-two sends against six, seven, seven and twenty priced. Each overrun was written into the notes as an outcome. Each failed step was answered with the review and the second send the rules asked for, while its cause stood in the steps not yet sent. Five of the six sends of the fifth wave that came back not done were one-line fixes the agent itself named, and each cost a review and a second send.

**What was wrong.** What the session measured was the plan's end. What the hub is for is the time and credit of the person it works for going to judgement only. A plan that reaches its end at three times its price has met the first and spent the second. The optimizing rule bound a plan's steps and not the session's own turns, and a turn that describes the gates in the place of the work is a cost like any other.

**What changed.** The dispatcher refuses a send past a plan's priced count and prints the count at every prompt. An agent repairs its own red check once, in a file it wrote in the send, and a second red check ends the step. The optimizing rule binds the session's own turns as well.

**The test.** Find the plan's Sends priced line and the count the status prints. A count past the number is a defect to be named with its causes, and the plan goes back through plan mode; it is never recorded as an outcome.

**The general form.** A price that nothing refuses past is a forecast. Say what a run will cost before it starts, hold the run to it by a refusal, and measure the cost and not the end.

**The measure.** The cost instrument run on this session's transcript, at the close of the plan of 10 November that made the change, is entered under P-10 of the program.
