## 410 · The rules-first fence would have latched every agent at its first call, and the agents a Workflow starts keep their transcripts where no reader looked

**Enforced by:** GATE hub:session-guards.test.mjs — the case for the plan read before the rules (the approved plan, or the steps file beside it, may be read first and nothing else may: another file, a write and a command stay refused with the rules named, and with no plan in force the plan's path is not special) and the case for a Workflow agent's transcript (the file list, the agent's own transcript by its payload, a running and an ended Workflow agent in the status reads, the fence judging its Read of the rules, and its latch letting it write its report), with plants that take out each allowance and each place looked in

**Recorded 2026-10-19.** Lesson 404 made an agent's first call the Read of the shared rules. An agent is sent only the plan's path and a step number, and it is the plan that names the rules file, so every agent of a session read the plan first, and the fence as built would have refused that Read, latched the agent at its first call and left it to hand back a refusal. Separately, the agents a Workflow starts keep their transcripts one level below `subagents/workflows/<run>/`, measured on this session's disk, and the status, the pointer, the stop guard and the plan fence all listed only the `subagents/` folder: a Workflow's agent was invisible to them, and the fence refused its every call for having no transcript.

**What is done now.** `rulesFirst` in `plan-fence.mjs` passes a Read of the approved plan's file, by the path the dispatch gate recorded, or of the steps file beside it, ahead of the Read of the rules, and passes nothing else; the Read of the rules stays required before any other call. `agentFiles`, `agentTranscriptPath` and `agentMeta` in `report.mjs` are the one place an agent's files are found, directly in `subagents/`, one level below `subagents/workflows/<run>/`, and one level below `<session>/workflows/<run>/` beside it, skipping a `scripts` folder and keeping the first file of an id. The status, the waits, the pointer, the stop guard, the latch's report allowance and the fence all read through them.

**What the check cannot see.** That the harness hands a hook the session transcript's path for a Workflow agent's call as it does for an agent started by the Agent tool; the session's folder is searched as a second route. The probe of whether the fence holds an agent inside a Workflow was not run, so the script gate of lesson 403 stays off.

**The general form.** A control that requires a first call names every call that must come before it, and the places a thing is looked for are one function, so a new place is added once.
