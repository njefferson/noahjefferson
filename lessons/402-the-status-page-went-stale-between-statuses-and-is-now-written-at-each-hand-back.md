## 402 · The status page was current only at a status, so it is now rewritten at each agent's hand-back as well, by the dispatcher, with nothing stamped

**Enforced by:** GATE hub:session-guards.test.mjs — the case for the status page at a hand-back (a task notification that carries an end marker, and an agent's hand-back, each write the page with the last status's own header; an owner message and a notice with no end marker write nothing; `report.mjs --page` stamps no clock, prints no status and writes no memory, and finds the session in the hook's payload or the shell's variable), with plants that take one of those out and must fail it

**Recorded 2026-10-18.** The page that holds the whole record of a plan run was written by the status command and by nothing else. An agent could end, the session be woken by the notice, and the page stay as it was until the manager gave a status, so a reader of the page, and the manager after a compaction, saw a state older than the last hand-back.

**Where it hooks in.** The dispatcher already receives the prompt that carries the notice of an agent's end: it is one of the harness's own prompts, a task notification with `<status>` completed, failed, killed, stopped or cancelled, or an agent's hand-back, and `recordOwnerTurn` already sets it aside as not the owner's. At that prompt `hook-dispatch.mjs` runs `report.mjs --page` (`isHandBackNotice`). No new event is wired in any settings file, so no install follows. The flag rewrites the page from the same read a status makes (`writeStatusPage`) and does nothing else: the clock is not stamped, nothing is printed, and the status memory is untouched, so the status gate, which is due when an agent has ended since the last status, and the page gate, which holds the first read after a compaction, are exactly what they were.

**What the check cannot see.** The test drives the prompt a hand-back is known to arrive as; whether the harness sends that prompt to the hook for every ending is taken from the way `recordOwnerTurn` already sets such prompts aside, and was not measured by the step that built this; a page that did not move after an ending is how a miss would show. The header carries the last status's own time and text, so a page written at a hand-back says plainly that it was written after that status.

**The general form.** A record that is meant to be current is written at the event that makes it stale, by the thing that already sees the event, and writing it must not be mistaken for the report that the owner is owed.
