## 427 · A plan reached its approval having been checked by nothing

**Enforced by:** CHECKLIST checks-before-the-talk-turn — the plan gate runs in a check mode before the talk turn, the review judges a plan before approval, and the approval waits on that judgement, so a refusal reaches the author before the person deciding reads the plan.

The plan gate ran only at the button, and the button comes after the talk turn. The review agent could be sent only under an approved plan. So a plan reached the approval with nothing having refused it. On 28 October one plan was refused at the button for a line that named who serves it, after the approval had already been given in words, which meant the approval had to be redone against a plan that had been read as correct.

A gate that first runs at the last step is the check the author learns from last. The hub plan carries the remedy: a check mode run before the talk turn, a review that judges a plan before approval, a button that waits on that judgement, and the latch taken off a refusal at the button.
