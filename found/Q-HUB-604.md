A session edits only the environment it runs in, so a change is made in a session on that environment or in its settings. It is a choice, in this order of recommendation:

1. Keep it open, where it is for reading sites that are not known ahead, on two conditions: no credential and no variable is ever saved on it, and its sessions run with no connector to mail or to files. The item is then closed with that reason.
2. Limit it to named hosts. A session there then asks for each new host on a card, which waits until it is seen.
3. Remove it, where it is no longer used.
