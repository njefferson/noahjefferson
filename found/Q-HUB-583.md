Q-HUB-583: Seen on 20 November 2026 by a made-up call put to the live dispatcher with the session's own record. The harness saves a tool result past a size to a file and leaves in the record an envelope that opens with the words persisted-output, with the result's first part after it. The approval of the page of 20 November, 120 thousand characters, was recorded that way, and the approvals of 19 November, 31 to 40 thousand characters, were not. The dispatcher counts an approval only where the result's text opens with the approval's own words, so it did not count that one, though the record beside the result holds the approved text and the file's path. Under it the launch of the run script for that page is refused on the top tier, a typed message with no go-word is not lifted by that approval, and an eject is not lifted by it.

Fix in: `hook-dispatch.mjs`, `guard-cases/dispatch.mjs`. The dispatcher counts an approval whose result the harness saved to a file, read from the envelope's first part and from the record beside the result, and a case holds it with a planted envelope.
